# Solaris

Соларпанк-прототип для хакатона. Реальные эко-дела дают энергию и биомассу, на них растёт город **Солнечный Нарын**.

Три экрана: город, квесты, след по CO₂. Фото квеста проверяет модель, маршрут отличает велосипед от машины, партнёрские точки принимают код.

## Запуск

```bash
npm install
npm run dev
```

Откройте `http://localhost:8080`.

Проверка фото на сервере читает `XAI_API_KEY`. Без ключа остальные квесты и город работают, а съёмка ответит, что проверка недоступна.

## Сборка

```bash
npm run typecheck
npm run build
```

## GitHub

Репозиторий публикуется из аккаунта владельца. В чате Grok это экспорт в GitHub. Из терминала, после `gh auth login`:

```bash
gh repo create solaris --public --source=. --remote=origin --push
```
